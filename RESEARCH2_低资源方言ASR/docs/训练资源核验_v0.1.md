# RESEARCH2 训练资源核验 v0.1

日期：2026-09-24

## 当前机器

- GPU：NVIDIA GeForce RTX 5070 Ti Laptop GPU
- 显存：12,227 MiB，总可用约 11.9 GiB；本次只读检查时空闲 9,142 MiB
- 驱动：580.88
- PyTorch CUDA：可用，设备数 1
- 已缓存模型：`openai/whisper-tiny`、`Systran/faster-whisper-small`

## 对当前实验的判断

1. Whisper-tiny full FT/LoRA 和 500 条级别的 task-control LoRA 可以在本机继续运行；当前已有成功 checkpoint 证明链路可用。
2. Whisper-base 的 LoRA/冻结 encoder 方案预计可行，但应从小 batch、gradient accumulation 和短 smoke 开始，不能直接按 tiny 的显存参数照搬。
3. Whisper-base full fine-tune、较大 batch 或长时间多轮训练可能触及显存/散热限制，应优先使用 LoRA、mixed precision 和 early stopping。
4. 当前没有缓存 `openai/whisper-base`，正式切换 base 前需要明确下载/联网策略；在 paired gate 通过前不提前下载或训练。

## 结论

5070 Ti 足以支撑本项目当前的 tiny 主线和小规模双输出 LoRA；base 适合作为第二阶段扩展，不是当前数据 gate 的阻塞点。当前真正阻塞正式四川话双输出实验的是人工规范文本尚未完成，而不是 GPU 能力。
