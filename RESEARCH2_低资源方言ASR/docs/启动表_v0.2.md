# RESEARCH2 启动与决策表 v0.2

日期：2026-09-24

## 研究主线

研究问题暂定为：在同一段方言语音上，能否通过显式任务控制或可组合 Adapter，在“方言保真转写”和“普通话规范化转写”之间切换，并保持说话人隔离、输出质量和跨方言迁移能力？

单纯的 LLM 规范化或单一输出 ASR 不作为主要创新点；WenetSpeech-Chuan 已覆盖大规模四川话 ASR 与规范化方向，因此我们的比较重点是双目标控制、Adapter 组合/路由和跨方言验证。

## 下一轮执行顺序

1. 检查 TSV 是否出现人工审核；若有，导回审核队列并运行安全落盘器。
2. 运行结构校验，确认 test 说话人没有进入标注训练集。
3. 只在 500 条中获得足够 `accepted/edited` 后，构造四川话 paired train/dev；保留原 test 说话人隔离。
   - 使用 `build_paired_manifest_from_annotations.py --dev-speakers ...` 将完整说话人放入 dev，避免同一说话人跨 train/dev；当前模板中可优先选择有足够样本的 G0008/G0019 等说话人，最终名单需在标注完成后按覆盖量确定。
4. 跑统一对照：zero-shot、方言 LoRA、规范 LoRA、task-control LoRA、独立 Adapter、组合/路由 Adapter。
5. 用 paired CER、方言特征词召回、规范化字符错误率、输出分离率和 bootstrap CI 汇报，不只看单一平均 CER。

## 偏离方向检查

- 若没有人工确认的规范文本，不训练正式四川话双输出模型；模型候选只能作为草稿。
- 若 task-control 只改变输出但不改善目标指标，记录为“可控但无质量增益”，不包装成 SOTA。
- 若简单 Adapter 相加持续产生干扰，转向条件路由/共享编码器+独立解码头，并保留负结果。
- 若四川话双文本标签长期无法获得，吴语只作为方法 pilot，不能替代四川话主结论。
