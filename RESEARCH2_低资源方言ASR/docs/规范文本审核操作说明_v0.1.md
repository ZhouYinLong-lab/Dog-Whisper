# 四川话规范文本审核操作说明 v0.1

目标：把同一段四川话音频的原始方言转写，补成普通话规范书面表达。当前只审核 500 条训练样本，不涉及四川话 dev/test 说话人。

## 1. 打开审核表

用 Excel/WPS 打开：

`sichuan_norm_annotation_template/norm_review_sheet_500.tsv`

只修改以下三列：

- `human_norm_text`：最终人工确认的普通话规范文本；
- `human_review_status`：填写 `accepted`、`edited` 或 `review`；
- `reviewer_note`：不确定时写原因。

`dialect_text`、`norm_text_candidate`、`candidate_flags`、`utt_id` 不要修改。候选文本只能作为草稿，必须核对原方言文本；明显不对时直接重写 `human_norm_text` 并标记 `edited`。

可以先分批处理高风险样本：

```powershell
python "RESEARCH 2/scripts/review_norm_tsv.py" export `
  --queue "RESEARCH 2/sichuan_norm_annotation_template/norm_review_queue_500.jsonl" `
  --priority high `
  --output "RESEARCH 2/sichuan_norm_annotation_template/norm_review_sheet_high12.tsv"
```

## 2. 标注规则

1. 保留原意、信息、数字、专名和句子边界；
2. 只把四川话词汇、口语形式、语气词和地区用字改为自然的普通话书面表达；
3. 不增加音频或原文中没有的信息；
4. 无法确定时不要猜，填写可接受的文本并标记 `review`，在 `reviewer_note` 说明原因；
5. `accepted` 表示接受候选，`edited` 表示人工修改后确认；
6. 目前不建议把 `review` 行用于正式训练。

## 3. 导回审核队列

在项目根目录运行：

```powershell
python "RESEARCH 2/scripts/review_norm_tsv.py" import `
  --queue "RESEARCH 2/sichuan_norm_annotation_template/norm_review_queue_500.jsonl" `
  --tsv "RESEARCH 2/sichuan_norm_annotation_template/norm_review_sheet_500.tsv" `
  --output "RESEARCH 2/sichuan_norm_annotation_template/norm_review_queue_500_reviewed.jsonl"
```

导回器会检查行数、`utt_id`、方言原文是否被修改；不完整或错位会直接失败。

分批审核时加 `--allow-partial`，它只更新表格中出现的行，其他行保留原状态：

```powershell
python "RESEARCH 2/scripts/review_norm_tsv.py" import `
  --queue "RESEARCH 2/sichuan_norm_annotation_template/norm_review_queue_500.jsonl" `
  --tsv "RESEARCH 2/sichuan_norm_annotation_template/norm_review_sheet_high12.tsv" `
  --output "RESEARCH 2/sichuan_norm_annotation_template/norm_review_queue_500_partial.jsonl" `
  --allow-partial
```

## 4. 生成正式标注与训练 manifest

审核完成后先运行：

```powershell
python "RESEARCH 2/scripts/finalize_sichuan_norm_annotations.py" `
  --template "RESEARCH 2/sichuan_norm_annotation_template/sichuan_norm_annotation_500.jsonl" `
  --review-queue "RESEARCH 2/sichuan_norm_annotation_template/norm_review_queue_500_reviewed.jsonl" `
  --output "RESEARCH 2/results/sichuan_norm_annotation_500_final.jsonl" `
  --require-complete
```

再按完整说话人切出 dev，避免 train/dev 泄漏。例如：

```powershell
python "RESEARCH 2/scripts/build_paired_manifest_from_annotations.py" `
  --annotation "RESEARCH 2/results/sichuan_norm_annotation_500_final.jsonl" `
  --output "RESEARCH 2/manifests/sichuan_paired_500.jsonl" `
  --dev-speakers "G0008,G0019" `
  --require-complete
```

最终训练前必须确认 summary 中 `ready_for_training=true`，并运行 `validate_research2_state.py --require-paired`。不要覆盖原始模板。
