# RESEARCH2 队友进度汇报（速用版）

日期：2026-09-29

## 30 秒口头汇报

目前完成了四川话数据审计和单目标 ASR 基线，也用公开吴语 benchmark 做过一轮双目标方法 pilot。吴语 pilot 在 68 条测试样本上验证了任务控制 LoRA 可以切换方言转写与普通话文本；但它没有说话人隔离，且任务控制相对独立 LoRA 的优势不显著，所以只能作为可行性结果。核心论文和数据状态已有初步核验；完整六基线、人工双版本标注、正式跨说话人评测尚未完成。下一步应先定主线和数据，再补实验，不能把 pilot 写成 SOTA 或最终结论。

## 文献与数据：目前能报告的结论

| 工作/资源 | 已解决的问题与可借鉴点 | 对本项目的限制 |
|---|---|---|
| [WenetSpeech-Wu（ACL Findings 2026）](https://aclanthology.org/2026.findings-acl.1395/) | 约 8,000 小时、8 种吴语次方言；Wu-Bench 覆盖 ASR 和吴语到普通话 AST，是最贴近吴语方案的数据与评测资源。官方仓库列出 ASR 9.75 小时、AST 3,000 条/4.4 小时。 | 本地 benchmark parquet 只有 task、utt_id、audio、label，无 speaker 字段；当前 pilot 不能做说话人独立结论。全量训练语料与 benchmark 要分开统计。 |
| [Betthupferl（Interspeech 2025）](https://arxiv.org/abs/2506.02894) | 德国三类方言约 4 小时，同时提供方言转写和标准德语转写；直接说明方言原文与标准化文本应作为不同目标分别评测。 | 是小规模评测资源和问题定义先例，不是中文方言 SOTA。 |
| [Efficient Dialect-Aware Modeling（台湾客家话，2026）](https://arxiv.org/abs/2602.22522) | 研究低资源客家话的方言感知建模，并联合汉字、拼音两种输出；说明“多输出/联合建模”本身不足以构成创新。 | 文字系统与普通话规范化任务不同，不能直接移植其结论。 |
| [ASR for Non-standardised Languages（VarDial 2020）](https://aclanthology.org/2020.vardial-1.2/) | 比较方言写法与标准化写法，显示输出规范会改变评测结论；可作为双 reference 评测动机。 | 年代较早、语种为瑞士德语，作为问题背景而非当前中文 SOTA。 |
| [ChinaVoices Challenge 2026](https://aslp-lab.github.io/ChinaVoices-Challenge/) | 提供中文多方言统一评测任务与规则，强调数据来源、测试划分、指标和复现条件统一。 | 更适合作为 benchmark/评测设计参考；挑战赛数据和模型结果不能等同于本地可复现训练资源。 |
| DASR-CPO（Interspeech 2026，待精读） | 会议目录出现该题名，聚焦低资源中文方言 ASR 的普通话语义漂移；提醒我们不要声称首次处理语义漂移。 | 目前只核对到会议目录题名，尚未完成全文、实验和代码核验；暂不引用具体性能结论。 |

以上是与队友方案最相关的六项，不代表穷尽全领域，也不应把所有工作统称为可直接比较的 SOTA：数据、方言、测试划分和任务定义不同。

## B0–B5 实验矩阵

| 编号 | 方案 | 状态与结果 |
|---|---|---|
| B0 | Whisper zero-shot | 吴语 pilot 已跑：方言 CER 0.9080，普通话 CER 0.9109（同一 68 条 test）。四川话另有小样本 zero-shot smoke，但尚未补成完整 2,572 条正式对照。 |
| B1 | 仅 `L_rec`，方言保真 ASR | 四川话 Whisper-tiny LoRA 已跑，speaker-disjoint test CER **0.4925**；这是目前最稳的完整单目标结果。 |
| B2 | 一个 LoRA + 任务 token/控制文本 | 吴语 Whisper-tiny pilot 已跑，方言/普通话 CER **0.8186/0.8445**；比 zero-shot 好，但测试集仅 68 条且无 speaker split。 |
| B3 | 两个独立 LoRA | 吴语 pilot 已跑，方言/普通话 CER **0.8245/0.8493**；与 B2 的差异没有显著性证据。 |
| B4 | `L_rec + L_norm` 组合 | 只试过两个 LoRA delta 等权直接相加，CER **1.0799/1.0827**，表现明显变差。它不等同于方案所说的“冻结基础模型与 `L_rec`，单独训练解码器 `L_norm` 后再加载”的完整实现。 |
| B5 | 方言 ASR → 文本规范化级联 | 尚未完成。 |

吴语 B0–B4 共用 68 条严格候选 test，属于方法 pilot；因为缺少 speaker ID，不能写成说话人隔离 benchmark。B2 对 B3 的 paired bootstrap 区间跨 0，目前只能说点估计接近，不能说 B2 更优。

## 汇报时可安全说 / 暂时不要说

可以说：

- 四川话单目标 LoRA 基线已跑通，speaker-disjoint test CER 为 49.25%。
- 吴语小样本 pilot 证明任务控制输出可以运行；直接相加两个 LoRA 在该 pilot 上有明显负面结果。
- 文献表明双文本转写、方言感知、多目标输出各有先例，创新需要落在严格的控制/组合比较与可信配对评测上。

暂时不要说：

- “六种方法都已经比较完”或“新方法已显著优于独立 LoRA”。
- “我们已经完成 500 条双版本实验”：四川话规范文本模板目前未完成人工标注。
- “Wu pilot 可代表跨说话人泛化”或“可代表四川话效果”。
- “首次提出双输出/双 LoRA/语音规范化”。

## 下一步最短路径

1. 若汇报沿用吴语方案：先把 B0–B4 明确标成 68 条 pilot，补 B5；同时说明公开 parquet 无 speaker 字段，正式泛化结论需要另找 speaker metadata 或重新构造测试集。
2. 若主实验按“优先用现有四川话数据”：保留 B1 为已完成基线；先由人工完成一批同音频规范文本，再跑 B2、B3、B5，之后决定是否值得实现完整 B4。
3. 把 DASR-CPO 和 ChinaVoices 相关正式论文/规则精读后再更新 novelty claim；当前先把方案定位为候选研究问题，不宣称创新已成立。
