# 07 初步设想的实验或改进方法

> 状态：后续计划，尚无本项目实验结果  
> 对应总报告：第 7 节

## 1. 本轮的定位

本文件只记录后续可能的实验方案，不代表已经下载数据、实现模型或得到结果。它的作用是判断文献调研能否自然落到可验证的研究问题。

## 2. 最小实验闭环

如果进入下一阶段，建议按以下顺序推进：

```text
带时间戳的对话数据
    → 严格因果的离线流式模拟
    → 固定静音阈值
    → RMS/能量 VAD
    → 轻量因果声学模型
    → latency、false-cutoff、F1
    → 停顿类型和错误样例分析
```

第一阶段不接 LLM、TTS，也不从零训练 ASR。目标是先确认标签、时间点和评分器可以闭环。

## 3. 可能的改进路线

### 路线 A：声学特征改进

在 VAD/静音时长之外加入能量变化、F0、语速、最近语音活动历史和局部停顿结构，使用轻量因果分类器。它的优点是输入延迟小、解释性较强；风险是说话人和场景差异可能较大。

### 路线 B：增量文本融合

在声学模型基础上加入已经到达的 partial transcript，比较词序列、句法完成度、疑问/陈述线索和简单语言模型分数。Maier 2017、Chang 2022 和 Coman 2019 都说明了增量词或语义状态具有研究价值，但文本延迟和 ASR 错误必须单独记录。[Maier（S06）](https://www.isca-archive.org/interspeech_2017/maier17_interspeech.html) [Chang（S11）](https://www.isca-archive.org/interspeech_2022/chang22_interspeech.html) [Coman（S09）](https://www.isca-archive.org/interspeech_2019/coman19_interspeech.html)

### 路线 C：错误驱动分析

不一开始追求复杂模型，而是先将 false cutoff 按思考停顿、填充词、重复、自我修正、backchannel、重叠和噪声分组。根据最主要的错误类型，再决定是否需要更复杂的标签或模型。

## 4. 预期比较方式

不以单个最高 F1 作为唯一目标，至少比较：

- 固定 FPR=5%/10% 时的 latency；
- 固定 latency 预算下的 false-cutoff；
- 各类停顿的误判率；
- 加入文本后的收益是否超过 ASR 延迟代价。

## 5. 止损线和风险

- 若专门 benchmark 无法获得授权，先使用公开且许可清晰的数据或缩小为方法综述；
- 若增量 ASR 难以获得，先只研究声学与静音策略，不把文本融合写成必须完成的部分；
- 若标签无法可靠定义，先报告不同标签协议对结论的影响；
- 若只得到分类指标而无法构造 latency/cut-in 评价，则不能声称改善了真实交互。

## 6. 当前结论

后续实验设计已经有最小可行路线，但是否进入实现阶段要等本轮 report 和导师反馈之后决定。
