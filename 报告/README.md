## 证据规则

- 统一来源编号、检索词和访问日期见 [调研过程与来源索引_v0.1.md](../调研过程与来源索引_v0.1.md)；
- 论文优先使用 ISCA Archive、ACL Anthology 等官方论文页；
- benchmark 和数据集优先使用项目官方页面或官方仓库；
- “已核验”表示已核对官方摘要、页面或 README，不等于已经完成论文全文精读；
- 本轮不把任何未运行的模型、未下载的数据或未复现的数字写成项目结果。
