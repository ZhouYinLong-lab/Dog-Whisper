# 05 与已有工作的区别

> 状态：初步完成，后续随文献更新  
> 对应总报告：第 5 节  
> 证据总账：[调研过程与来源索引](../调研过程与来源索引_v0.1.md)

## 1. 先明确：不把已有工作当作空白

声学特征、词特征、增量 ASR、TRP、连续轮次预测、VAP 和音频—文本融合都已有先例。Maier 2017 已经比较了 live acoustic 与 lexical information；Chang 2022 已经研究了 ASR 与暂停/结束判断的联合；Ekstedt 2022 已经提出自监督 VAP。因此，单纯“换一个分类器”或“把 audio 和 text 拼接起来”不足以成为创新点。[Maier（S06）](https://www.isca-archive.org/interspeech_2017/maier17_interspeech.html) [Chang（S11）](https://www.isca-archive.org/interspeech_2022/chang22_interspeech.html) [VAP（S10）](https://www.isca-archive.org/interspeech_2022/ekstedt22_interspeech.html)

## 2. 暂定区别

| 维度 | 已有工作常见情况 | 本方向暂定切入点 |
|---|---|---|
| 任务 | EOT、TRP、turn-shift、VAP 等定义不完全一致 | 明确限定为因果 EOT/endpoint decision，并说明与其他任务的关系 |
| 信息可见性 | 不同论文对完整转写、增量文本和未来窗口处理不同 | 统一记录每个时刻实际可见的信息和 ASR 延迟 |
| 比较方式 | 常以单一数据集、单一模型或单一 F1 为主 | 在统一协议下比较阈值、声学、增量文本和融合模型 |
| 评价目标 | 召回率、准确率和 latency 的报告方式不统一 | 固定 false-cutoff/FPR 预算，观察 latency–cut-in 曲线 |
| 错误分析 | 总体指标多，停顿类型拆分不足 | 分析思考停顿、未完成句、backchannel 和重叠等错误 |
| 可复现性 | 数据、代码和标签权限不同 | 优先选择公开 benchmark，记录许可证、版本和评分器 |

## 3. 可能形成的贡献

如果后续实验能够支持，贡献可以表述为：

1. 一套严格因果的端点检测比较协议；
2. 在固定误截断预算下对不同输入信号的实证比较；
3. 对停顿类型和对话场景的错误分析；
4. 对增量文本收益及其延迟代价的定量讨论。

这些属于“统一评价与实证分析型”贡献，不是“提出全新端点检测范式”。TurnBench 的出现使这类贡献更容易被放在公开标准上讨论，但也意味着必须避免重复已有 benchmark 结果。[TurnBench（S13/S14）](https://turnbench.sesame.com/)

## 4. 需要后续核验的区别

- TurnBench 是否已有完全相同的 threshold/acoustic/partial-text 对照；
- Maier、Chang 和 Uro 的数据与评价是否可以严格对应；
- 现有公开模型是否已报告固定 FPR 下的 latency；
- 错误类型分析是否已有系统性分类。

在这些项目核验前，正式文本中使用“拟比较”“可能贡献”而不是“我们首次提出”。
